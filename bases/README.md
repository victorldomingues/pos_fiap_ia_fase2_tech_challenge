# 🏥 Base de Hospitais e Leitos do SUS  
Origem, descrição e informações oficiais

## 📌 Visão Geral  
Este repositório utiliza dados públicos disponibilizados pelo **Portal de Dados Abertos do SUS**, mantido pelo Ministério da Saúde do Brasil.  
A base contém informações detalhadas sobre **estabelecimentos hospitalares**, **quantidade de leitos gerais e complementares**, além de **dados de contato e localização** das unidades de saúde.

---

## 📂 Origem da Base  
Os dados são provenientes do conjunto **Hospitais e Leitos**, disponível no portal oficial:

**Fonte oficial:**  
Portal de Dados Abertos do SUS – Hospitais e Leitos [(dadosabertos.saude.gov.br in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fdadosabertos.saude.gov.br%2Fdataset%2Fhospitais-e-leitos")

**Recurso específico utilizado:**  
[Leitos 2026 – CSV](https://dadosabertos.saude.gov.br/dataset/hospitais-e-leitos/resource/5ac78b13-649f-4b09-8a92-0ae829a56d50)

Segundo o portal, este recurso contém:

- Dados gerais dos estabelecimentos hospitalares  
- Quantidade de leitos gerais e complementares  
- Informações de contato (endereço, telefone etc.)  
- Identificação e classificação dos estabelecimentos

## 🗂️ Estrutura do Arquivo  
O arquivo CSV é disponibilizado como parte do pacote:

```
Leitos_SUS/Leitos_csv_2026.zip
```

Ele contém registros tabulares com informações de cada estabelecimento hospitalar, incluindo:

- Código CNES  
- Nome do estabelecimento  
- Tipo de gestão  
- Quantidade de leitos por categoria  
- Endereço completo  
- Município e UF  
- Contatos  
- Classificações complementares
